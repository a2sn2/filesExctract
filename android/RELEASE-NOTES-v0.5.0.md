# FilesExtract Mobile v0.5.0

First Android product release.

- Android 8.0+ (`minSdk 26`), target SDK 35.
- Local extraction for PDF, DOCX, XLSX/XLSM and PPTX.
- On-device OCR fallback for scanned PDF pages.
- Structured JSON and readable Markdown output.
- Office media assets exported with SHA-256 manifest.
- Security limits for untrusted ZIP/OOXML documents.
- Macros/OLE are detected but never executed.
- Automated unit, lint, APK build and emulator extraction gate.
